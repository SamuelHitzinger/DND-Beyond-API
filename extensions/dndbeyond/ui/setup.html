Connection help

The API connects automatically and uses your remembered character.

Checking connection…

Sign in to D&D Beyond in this browser, then choose your character in the extension.

If the Windows helper is unavailable, run Install.cmd from your permanent package folder. No developer tools or .NET installation are needed.

Use the extension in one browser profile at a time. Close the other browser, or disable the extension in that profile, before switching.

If sign-in expires, sign in again and refresh the characters. In Brave, allow D&D Beyond sign-in cookies if Shields blocks them.

If required site access was disabled manually, restore it in the browser's extension settings. There is no separate approval inside this extension.

Character pickerAPI reference and examples are included in the package.
